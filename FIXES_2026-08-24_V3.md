# Wedding Website Fixes — 24 Aug 2026 v3

## Confirmed issues from browser console
- Google Drive intro video was blocked by CSP `media-src`.
- Google Drive images were blocked by CSP `img-src`.
- YouTube iframe was blocked because `frame-src` was not defined.
- Admin Backspace could invoke browser history navigation when focus was not in an editable field.
- Admin feedback was not reliably visible at the top after actions.
- Save/refresh actions could change scroll position.
- Groom/Bride Drive images had no runtime fallback if the remote image failed.

## Fixes
1. Added a same-origin `/api/media?id=...` Google Drive media proxy for homepage images/video. It forwards Range requests so video playback can stream normally.
2. Homepage Drive media now uses the same-origin proxy instead of relying on Google Drive redirects in the browser.
3. Added fallback Drive URLs for the intro video.
4. Added runtime fallback images for Groom and Bride.
5. Updated CSP to explicitly allow YouTube frames and Drive media/image origins.
6. Added a global Admin Backspace guard: Backspace works normally inside input/textarea/select/contenteditable, but cannot navigate browser history from the Control Center when no editable element is focused.
7. Added sticky top Control Center success/error alerts.
8. Save/action operations now preserve the user's scroll position.
9. All Admin buttons explicitly use `type="button"`.
10. URL/Drive checks now display success messages as success alerts instead of red error messages.

## Deployment requirement
The Vercel environment must contain `GOOGLE_DRIVE_API_KEY` on the server because `/api/media` uses the server-side Drive API key. The referenced Drive files must be accessible to that Google Drive API key/public access configuration.
